# 通用能力技能卡：知识库 · 文档问答（knowledge）

> 用途：检索本地 `knowledge/` 目录和用户上传资料中的原文，回答产品说明、手册、FAQ、内部政策等问题。

## 1. 什么时候用
问题涉及“文档里写了什么 / 报销标准 / 使用说明 / 政策 / 手册 / 上传的 PDF/Word/Markdown 内容”时使用。

## 2. 标准流程
1. 调用 `search_knowledge(query=用户原问或提炼后的关键词)`。
2. 工具会返回最相关的原文片段、来源文件名、段落号，以及关键词 / 语义向量引擎说明。
3. 只依据命中的片段回答，并说明来源；没命中就如实说“知识库中没有检索到”。

## 3. 易错点
- 不要用 `search_knowledge` 去查 MySQL 业务库的实时数据；业务取数用 `get_table_schema + execute_sql`。
- 不要把检索片段当成实时表结构；两者冲突时以数据库实时结构为准。
- 没有命中时不得编造资料内容。
