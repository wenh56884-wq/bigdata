# 通用能力技能卡：机器学习 · 趋势预测（forecast）

> 用途：用 sklearn 对金融 / 医疗 / 通信三个库的月度指标建模，预测未来若干个月并生成报告。

## 1. 什么时候用
用户要求“预测 / 未来某个月 / 趋势走向 / 用机器学习 / 生成预测报告”时使用。

## 2. 标准流程
1. `list_forecast_metrics()` 查看可用指标 key 与所属库。
2. 选好指标后调用 `forecast_metric(metric='指标key', horizon=月数)`。
3. 需要三个库都预测时，对每个库各选一个代表指标依次调用。
4. 工具会返回逐月预测值和趋势结论，并自动生成 `reports/*.md` 报告文件。
5. 最终回答给出关键数字、趋势结论和报告文件路径；不要描述内部建模步骤。

## 3. 易错点
- 先看 `list_forecast_metrics`，不要凭印象猜 metric key。
- horizon 是月数，不是年数。
- 预测是趋势推断，不是真实发生值，回答时要说明“预测值”。
