# 通用能力技能卡：数据分析 · 图表可视化（visualization）

> 用途：把“最近一次查询结果”画成折线 / 柱状图，并在最终回答中展示图片。

## 1. 什么时候用
用户明确要求“画图 / 可视化 / 走势图 / 占比分布 / 图表”时，先查数、再画图。

## 2. 标准流程
1. 先取数：
   - 业务库：`execute_sql` 查 MySQL；
   - 非结构化表格库：`find_table → describe_table → query_tables` 查 SQLite。
2. 再调用 `plot_last_result(title=..., x_col=..., y_cols=...)`。
3. 最终回答必须引用工具返回的图片地址，例如：
   `![图表标题](/reports/chat_xxx.png)`
   不要自己编图片文件名。

## 3. 参数建议
- `title`：图标题；留空会自动生成。
- `x_col`：横轴列，通常选日期、月份、名称、类别列；留空自动选。
- `y_cols`：数值列，多个用英文逗号分隔；留空自动选所有数值列。

## 4. 易错点
- 必须先查询再画图；`plot_last_result` 只使用“最近一次查询”的缓存。
- 业务库或表格库都可以，但不要重复取数。
- 若工具返回“暂无可绘图数据”，说明要先执行查询。
